# Учебная смена кассира

Это окно учебного профиля. Надпись на экране говорит, что расчёты с покупателем не проводятся. Учебный терминал подтверждает сумму внутри программы и не является Kaspi. Учебное правило `TRAINING_NO_RECEIPT` не печатает чек Webkassa и не описывает налоговую схему.

Промышленный профиль (`AGZS_ENV=production`) это окно может открыть, но продажу не создаёт: нет утверждённого округления, фискальное правило остаётся `DENY_ALL`, а `Aska02Adapter` отклоняет обмен.

## Запуск

```bash
python -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/pip install "agzs-station[ui]"
AGZS_ENV=emulator AGZS_PUMP_DRIVER=emulator .venv/bin/agzs-station --ui
```

Пароль первого кассира `cashier` берётся из `AGZS_BOOTSTRAP_PASSWORD`. Если переменная пустая, программа один раз записывает пароль в `data/bootstrap-password.txt` и не печатает его в журнал.

## Пульт

Окно устроено как операторский пост колонок. У каждой колонки своя лампа и табло: сумма в тенге, доза в литрах и суммарный счётчик. Пока наблюдение не подтверждено, цифры отпуска скрыты и лампа показывает «НЕТ СВЯЗИ».

1. Войти. Смена открывается сама, если её ещё нет.
2. Нажать колонку. Свободная горит зелёным, «СВОБОДНА».
3. Набрать дозу кнопками: режим «Сумма» — целые тенге, режим «Литры» — объём, программа сама переводит его в тенге по цене колонки.
4. «ПУСК» проводит учебную оплату и открывает отпуск. Повторный пуск той же продажи не создаёт вторую попытку.
5. Во время «НАЛИВ» табло считает сумму и дозу. «СТОП» на учебной модели останавливает набор. На боевой колонке кнопка экрана газ не закрывает: для этого аппаратная кнопка, а «Блокировка пуска» только запрещает новые команды.
6. «Сброс дозы» очищает набор и последнее табло выбранной колонки.
7. Если факт меньше предоплаты, ось расхождения становится `ADJUSTMENT_REQUIRED`. Возврат сам не проводится.
8. Закрыть смену можно, когда нет незавершённой оплаты и колонка не в `DISPENSING` или `READY`. Открытое расхождение закрытию смены не мешает.

Кнопки обрыва и восстановления звена видны только в учебном профиле.
