# AGZS Control

Система автоматизации автомобильных газозаправочных станций: локальная касса на Windows и центральный сервер на Ubuntu.

Сейчас готовы этап 1 (проект) и этап 2 (каркас кассы). Деньги хранятся целыми тенге. Эмулятор колонок, продажи, Kaspi, Webkassa и API сервера ещё не реализованы.

## Локальный запуск каркаса

```bash
python -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest
```

Переменные окружения перечислены в `.env.example`. Пустые значения не подставляют адреса и секреты. Файл `.env` не коммитится.

Промышленный профиль (`AGZS_ENV=production`) собирается только с драйвером `aska02`. Этот драйвер пока отклоняет обмен. Профиль `emulator` не подключается к оборудованию; модель колонок начнётся на этапе 3.

```bash
AGZS_ENV=production AGZS_PUMP_DRIVER=aska02 .venv/bin/agzs-station
```

Команда создаёт локальную базу SQLite и пишет структурный журнал. Окна кассира ещё нет.
