# AGZS Control

Система автоматизации автомобильных газозаправочных станций: локальная касса на Windows и центральный сервер на Ubuntu.

Сейчас выполнен только этап 1 — проектирование. Код приложений, миграции и обмен с оборудованием ещё не начинались. Этап 2 начинается после отдельного подтверждения.
